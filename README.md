# PubBot
A personal Discord server bot. Originally created in 2021, it got a massive overhaul starting in 2025. Made for SirHadoken and the Hado's Pub Discord server.

It's not recommended to clone this repo unless you want to go through the scavenger hunt of "what do the `.env` files need".

## Features
- Integrations with pm2 for machine-based uptime
- Whitelist request system - filling out a form submits a request for your Newgrounds account to be whitelisted for Geometry Dash usage. Also notifies when the request was accepted or denied (provided the user is still on the server).
- Infraction system
- Auto-updating image of current server mods/admins (courtesy of Canvas JavaScript API)
- Music playlist functionalities from YouTube, Spotify or Soundcloud
- System logging, including fancy print for console
- XP system with leaderboard and role functionality
